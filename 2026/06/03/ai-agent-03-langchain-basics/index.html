聊聊AI Agent（三）：LangChain入门

2026-06-03 AI Agent系列 AI, LLM, LangChain, Python 0 Comments Word Count: 2k(words) Read Count: 9(minutes)

前言

在上一篇文章中，我们了解了RAG的概念和实现。你可能会发现，实现一个RAG系统需要处理很多细节，比如文档加载、文本分割、向量化、检索等等。有没有一个框架可以帮我们简化这些操作呢？答案就是LangChain。今天就来聊聊LangChain是什么，以及如何使用它来构建AI应用

什么是LangChain

LangChain是一个用于构建LLM应用的开源框架。它提供了一系列工具和组件，让开发者可以更轻松地构建基于大语言模型的应用

用通俗的话来说，LangChain就是一个”胶水框架”，它把各种LLM相关的工具和组件粘合在一起，让我们可以快速构建AI应用

LangChain的核心概念

LangChain有几个核心概念，我们来逐一了解

1. Models（模型）

Models是LangChain的核心组件，它封装了各种LLM的调用接口

2. Prompts（提示词）

Prompts负责构建发送给LLM的提示词

3. Chains（链）

Chains是LangChain的核心抽象，它将多个组件串联起来

4. Memory（记忆）

Memory让链能够记住之前的对话

5. Tools（工具）

Tools让LLM能够与外部世界交互

6. Agents（代理）

Agents是LangChain中最强大的组件，它让LLM能够自主决策使用哪些工具

总结

今天我们了解了LangChain的基本概念

  1. 什么是LangChain：用于构建LLM应用的开源框架
  2. 为什么需要LangChain：简化LLM应用的开发
  3. LangChain的核心概念：
    • Models：模型封装
    • Prompts：提示词模板
    • Chains：组件串联
    • Memory：对话记忆
    • Tools：外部工具
    • Agents：智能代理
  4. LangChain的使用场景：对话机器人、文档问答、代码生成、数据分析
