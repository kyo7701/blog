聊聊AI Agent（三）：LangChain入门

2026-06-03 AI Agent系列 AI, LLM, LangChain, 框架 0 Comments Word Count: 1.7k(words) Read Count: 6(minutes)

前言

在上一篇文章中，我们了解了RAG的概念和实现。你可能会发现，实现一个RAG系统需要处理很多细节，比如文档加载、文本分割、向量化、检索等等。有没有一个框架可以帮我们简化这些操作呢？答案就是LangChain。今天就来聊聊LangChain是什么，以及它的核心概念

什么是LangChain

LangChain是一个用于构建LLM应用的开源框架。它提供了一系列工具和组件，让开发者可以更轻松地构建基于大语言模型的应用

用通俗的话来说，LangChain就是一个”胶水框架”，它把各种LLM相关的工具和组件粘合在一起，让我们可以快速构建AI应用

为什么需要LangChain

那么为什么需要LangChain呢？我们来看看没有LangChain时的开发体验

没有LangChain

如果我们要构建一个RAG系统，需要：

  1. 调用OpenAI API
  2. 实现文档加载逻辑
  3. 实现文本分割逻辑
  4. 调用嵌入模型API
  5. 使用向量数据库API
  6. 实现检索逻辑
  7. 构建提示词
  8. 处理错误和重试

每一步都需要自己实现，代码量大，容易出错

有LangChain

有了LangChain，我们可以：

  1. 使用内置的文档加载器
  2. 使用内置的文本分割器
  3. 使用内置的嵌入模型封装
  4. 使用内置的向量数据库封装
  5. 使用内置的检索器
  6. 使用内置的提示词模板
  7. 使用内置的错误处理

大大简化了开发流程

LangChain的核心概念

LangChain有几个核心概念，我们来逐一了解

1. Models（模型）

Models是LangChain的核心组件，它封装了各种LLM的调用接口

模型的分类：

  • LLM模型：文本补全模型，如GPT-3
  • 聊天模型：对话模型，如GPT-4、Claude
  • 嵌入模型：文本向量化模型，如text-embedding-ada-002

模型的作用：

  • 统一不同LLM的调用接口
  • 处理API认证和错误
  • 支持流式输出
  • 支持缓存和重试

2. Prompts（提示词）

Prompts负责构建发送给LLM的提示词

提示词的类型：

  • PromptTemplate：简单的模板，支持变量替换
  • ChatPromptTemplate：聊天模板，支持系统消息、用户消息
  • FewShotPromptTemplate：少样本模板，支持示例

提示词的作用：

  • 格式化用户输入
  • 添加系统指令
  • 提供示例
  • 控制输出格式

3. Chains（链）

Chains是LangChain的核心抽象，它将多个组件串联起来

链的类型：

  • LLMChain：最基本的链，包含提示词和模型
  • SequentialChain：顺序链，多个链依次执行
  • RouterChain：路由链，根据条件选择不同的链

链的作用：

  • 组合多个组件
  • 定义执行流程
  • 处理数据流转

4. Memory（记忆）

Memory让链能够记住之前的对话

记忆的类型：

  • ConversationBufferMemory：记住所有对话
  • ConversationBufferWindowMemory：记住最近k轮对话
  • ConversationSummaryMemory：压缩对话历史
  • ConversationEntityMemory：记住实体信息

记忆的作用：

  • 支持多轮对话
  • 维护上下文
  • 减少token消耗

5. Tools（工具）

Tools让LLM能够与外部世界交互

工具的类型：

  • 搜索工具：搜索引擎、知识库
  • 计算工具：计算器、代码执行器
  • 文件工具：文件读写、格式转换
  • API工具：调用外部API

工具的作用：

  • 扩展LLM的能力
  • 获取实时信息
  • 执行具体操作

6. Agents（代理）

Agents是LangChain中最强大的组件，它让LLM能够自主决策使用哪些工具

Agent的工作原理：

  1. 接收用户任务
  2. LLM分析任务，决定使用哪个工具
  3. 执行工具，获取结果
  4. LLM分析结果，决定下一步
  5. 重复直到任务完成

Agent的优势：

  • 自主决策
  • 灵活应对
  • 处理复杂任务

LangChain的架构设计

模块化设计

LangChain采用模块化设计，每个组件都是独立的模块

可组合性

组件之间可以自由组合，构建不同的应用

可扩展性

可以轻松添加新的组件

  • 自定义模型
  • 自定义工具
  • 自定义链
  • 自定义记忆

LangChain的使用场景

1. 对话机器人

使用LangChain构建智能对话机器人

  • 支持多轮对话
  • 记住用户偏好
  • 调用外部工具

2. 文档问答

使用LangChain构建文档问答系统

  • 加载各种格式的文档
  • 智能检索相关内容
  • 生成准确回答

3. 代码生成

使用LangChain构建代码生成工具

  • 理解需求描述
  • 生成代码
  • 测试和调试

4. 数据分析

使用LangChain构建数据分析工具

  • 加载数据
  • 分析数据
  • 生成报告

LangChain vs 其他框架

LangChain vs LlamaIndex

特性 LangChain LlamaIndex
定位 通用LLM应用框架 数据索引和检索
优势 组件丰富、生态完善 索引优化、检索精准
适用场景 复杂应用 RAG场景

LangChain vs Haystack

特性 LangChain Haystack
定位 通用LLM应用框架 NLP管道框架
优势 社区活跃、更新快 成熟稳定、文档完善
适用场景 快速原型 生产环境

LangChain的生态系统

LangSmith

LangSmith是LangChain的监控和调试平台

功能：

  • 追踪LLM调用
  • 监控性能
  • 调试错误
  • 评估质量

LangServe

LangServe用于将LangChain应用部署为API

功能：

  • 自动创建API
  • 支持流式输出
  • 提供文档

LangGraph

LangGraph用于构建复杂的AI工作流

功能：

  • 图结构
  • 状态管理
  • 人工干预

LangChain的最佳实践

1. 选择合适的模型

  • 根据任务选择模型
  • 考虑成本和性能
  • 测试不同模型

2. 优化提示词

  • 清晰的指令
  • 提供示例
  • 控制输出格式

3. 使用缓存

  • 缓存LLM调用
  • 减少成本
  • 提升性能

4. 错误处理

  • 重试机制
  • 降级策略
  • 日志记录

5. 监控和评估

  • 追踪调用
  • 监控性能
  • 评估质量

总结

今天我们了解了LangChain的基本概念

  1. 什么是LangChain：用于构建LLM应用的开源框架
  2. 为什么需要LangChain：简化LLM应用的开发
  3. LangChain的核心概念：
    • Models：模型封装
    • Prompts：提示词模板
    • Chains：组件串联
    • Memory：对话记忆
    • Tools：外部工具
    • Agents：智能代理
  4. LangChain的架构设计：模块化、可组合、可扩展
  5. LangChain的使用场景：对话机器人、文档问答、代码生成、数据分析
  6. LangChain的生态系统：LangSmith、LangServe、LangGraph

LangChain是构建AI Agent的重要工具，在接下来的文章中，我们将深入学习LangChain的高级特性和LangGraph
